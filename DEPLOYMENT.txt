========================================
DEPLOYMENT GUIDE - CAR RENTAL SYSTEM
========================================

Your app is now ready for FREE cloud deployment!

OPTION 1: RENDER (RECOMMENDED)
===============================

1. CREATE GITHUB REPOSITORY:
   - Go to github.com and create a new repository
   - Push your code:
     git init
     git add .
     git commit -m "Initial commit"
     git branch -M main
     git remote add origin YOUR_GITHUB_REPO_URL
     git push -u origin main

2. DEPLOY ON RENDER:
   - Sign up at render.com (free, no credit card needed)
   - Click "New" -> "Web Service"
   - Connect your GitHub repository
   - Render will auto-detect the render.yaml file
   - Click "Create Web Service"
   - Wait 2-5 minutes for deployment
   - Your site will be live at: https://car-rental-system.onrender.com

3. IMPORTANT NOTES:
   - Free tier sleeps after 15 min of inactivity
   - First request after sleep takes ~30 seconds
   - Data persists in JSON files but may reset on redeploy


OPTION 2: RAILWAY
=================

1. Push code to GitHub (see steps above)

2. Deploy on Railway:
   - Sign up at railway.app
   - Click "New Project" -> "Deploy from GitHub"
   - Select your repository
   - Railway auto-detects and deploys
   - Get $5 free credit monthly

3. Your app will be live at: https://your-app.up.railway.app


OPTION 3: VERCEL (FRONTEND ONLY)
=================================

For static frontend hosting:
1. Sign up at vercel.com
2. Import project from GitHub
3. Set root directory to "frontend"
4. Deploy!

Note: You'll need separate backend hosting (use Render/Railway)
